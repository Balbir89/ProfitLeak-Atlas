# Start here — ProfitLeak Atlas Expert Release

1. **Dashboard:** Open `docs/index.html`. It links to the interactive case explorer and the public-data quality pilot. Open `docs/explore.html` in a browser to use the case filters and recovery slider.
2. **On laptop:** Open `excel/ProfitLeak_Atlas_Expert.xlsx` for the original Excel workbook.
3. **On Windows with Power BI Desktop:** Open `powerbi/ProfitLeak_Atlas_PBIP/ProfitLeak_Atlas.pbip`; follow `docs/powerbi_verification.md`. **It has passed offline checks, but Desktop execution has not been verified.**
4. **Rebuild from source:** Run `python src/rebuild.py` from the project root.
5. **For GitHub:** See `docs/GITHUB_PUBLISH_GUIDE.md`.

All corporate financial scenario amounts are **synthetic**. The public Chicago data-quality pilot cannot establish fraud, recovered money, or production model accuracy.
